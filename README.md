# LeaveFlow - ระบบจัดการวันเวลาของการลา (Leave Management System)

ระบบจัดการวันเวลาของการลา **LeaveFlow** ถูกพัฒนาขึ้นอย่างประณีตตามต้นแบบ UI ในไฟล์ `Green Leave Management Dashboard.png` โดยใช้เทคโนโลยีสมัยใหม่ **React (Vite) + Tailwind CSS + Lucide Icons + Canvas Confetti**

---

## 🌿 ฟีเจอร์หลักของระบบ (Key Features)

### 0. ระบบเข้าสู่ระบบ (Authentication & Sign-in System) 🆕
- **หน้า Login สไตล์ Modern Corporate**: โทนสีเขียวธรรมชาติของ LeaveFlow พร้อมภาพประกอบและสรุปฟีเจอร์เด่น
- **บัญชีทดสอบคลิกเดียว (One-Click Demo Accounts)**:
  1. **นางสาวพนิกา ธรรมเมือง (พนักงาน)**: อีเมล `panika.t@leaveflow.com` (รหัสผ่าน: `123456`)
  2. **นายสมชาย มั่นคง (ผู้จัดการ/ผู้อนุมัติ)**: อีเมล `somchai.m@leaveflow.com` (รหัสผ่าน: `123456`)
- ฟังก์ชันซ่อน/แสดงรหัสผ่าน (Eye toggle) และระบบตรวจสอบความถูกต้อง
- ออกจากระบบ (Logout) จากเมนูด้านซ้ายหรือโปรไฟล์ด้านบน เพื่อกลับสู่หน้าเข้าสู่ระบบ

### 1. หน้าหลัก (Dashboard) - ตรงตามต้นแบบ 1:1
- **Sidebar การนำทาง**: โลโก้ LeaveFlow ลายใบไม้ เมนูครบครัน (หน้าหลัก, ขอลา, ประวัติการลา, ปฏิทินการลา, ผู้อนุมัติ/ผู้ดูแล, รายงาน, ตั้งค่า, ออกจากระบบ) พร้อมภาพประกอบใบไม้ตกแต่งด้านล่าง
- **แถบนำทางส่วนบน (Top Header)**:
  - ช่องค้นหาทรงกระบอก (Pill Search)
  - กระดิ่งแจ้งเตือนพร้อม Badge สีแดง (แจ้งเตือน 3 รายการล่าสุด สามารถคลิกอ่านได้จริง)
  - ข้อมูลผู้ใช้ **นางสาวพนิกา ธรรมเมือง (พนักงาน)** พร้อมระบบสลับบทบาท (Demo Role Switcher) ระหว่างพนักงานและผู้จัดการ
- **Hero Welcome Banner**: แบนเนอร์ทักทาย *"สวัสดีค่ะ คุณพนิกา 👋 ยินดีต้อนรับสู่ระบบจัดการวันเวลาของการลา"* พร้อมภาพประกอบปฏิทิน นาฬิกา และใบไม้กราฟิกสไตล์มินิมอล
- **การ์ดสรุปยอดวันลา (Stat Summary Cards - 4 การ์ด)**:
  1. วันลาคงเหลือ: 12 วัน (จาก 15 วัน/ปี) พร้อมแถบความคืบหน้า
  2. ลาพักร้อน: 8 วัน (จาก 10 วัน)
  3. ลากิจส่วนตัว: 3 วัน (จาก 5 วัน)
  4. ลาป่วย: 5 วัน (จาก 10 วัน)
- **วิดเจ็ตปฏิทินการลา (Calendar Widget)**:
  - แสดงปฏิทินเดือนพฤศจิกายน 2568 ตรงตามดีไซน์
  - จุดกำกับและไฮไลต์สถานะการลา (วันที่ 3, 12, 14, 20, 22)
  - สามารถคลิกที่วันเพื่อดูรายละเอียด และเลื่อนดูเดือนอื่นๆ ได้
- **ประกาศจากฝ่ายบุคคล (HR Announcement)**:
  - การแจ้งวันหยุดนักขัตฤกษ์ประจำเดือนธันวาคม 2568
  - ปุ่ม *"ดูทั้งหมด >"* เปิดป๊อปอัปประกาศทั้งหมด
- **รายการการลา ล่าสุด (Recent Leave Requests)**:
  - แสดงตาราง 4 รายการตรงตามดีไซน์ (20-21 พ.ย., 12 พ.ย., 5 พ.ย., 28 ต.ค.)
  - ป้ายสถานะสีเขียว (อนุมัติ) และสีส้ม (รออนุมัติ)
  - สามารถคลิกแต่ละแถวเพื่อเปิดดู Modal รายละเอียดฉบับเต็ม
- **การ์ด Quick Action**: *"ของ่าย อนุมัติไว"* พร้อมปุ่ม *"ขอลาเลย ->"*

---

### 2. ระบบการขอลา (Leave Request Modal)
- เลือกประเภทการลา (ลาพักร้อน, ลากิจส่วนตัว, ลาป่วย) พร้อมแสดงโควตาคงเหลือแบบ Real-time
- เลือกวันเริ่มต้น - วันสิ้นสุด
- เลือกช่วงเวลา: เต็มวัน / ครึ่งวันเช้า / ครึ่งวันบ่าย
- คำนวณจำนวนวันลาอัตโนมัติ
- ระบุเหตุผลการลา, เลือกผู้ปฏิบัติงานแทน, จำลองการแนบไฟล์เอกสาร
- เมื่อกดยื่นคำขอ มีเอฟเฟกต์ **Confetti** และข้อมูลจะถูกอัปเดตลงในตาราง ปฏิทิน และการแจ้งเตือนทันที

---

### 3. ประวัติการลา (Leave History)
- กรองตามสถานะ: ทั้งหมด / รออนุมัติ / อนุมัติแล้ว / ไม่อนุมัติ / ยกเลิก
- กรองตามประเภทการลา
- ค้นหาตามคำสำคัญ
- ปุ่มส่งออกเป็นไฟล์ **CSV (Excel compatible)**
- สามารถกดยกเลิกคำขอที่ยังรออนุมัติได้

---

### 4. ปฏิทินการลาขององค์กร (Calendar View)
- แสดงปฏิทินขนาดใหญ่ขององค์กร
- สลับมุมมองระหว่าง "เฉพาะของฉัน" และ "บุคลากรทั้งหมดในองค์กร"
- แสดงแถบสีของแต่ละประเภทการลาในแต่ละวัน

---

### 5. พอร์ทัลผู้อนุมัติ / ผู้ดูแล (Approver Portal)
- ตรวจสอบรายการที่ส่งมาจากพนักงาน (รวมถึงรายการรออนุมัติของพนิกา)
- สามารถคลิก **"อนุมัติคำขอ"** หรือ **"ไม่อนุมัติ"** พร้อมกรอกข้อคิดเห็น
- เมื่ออนุมัติ โควตาวันลาและสถานะจะซิงก์กลับไปยังหน้า Dashboard และแจ้งเตือนทันที

---

### 6. รายงานสถิติการลา (Reports & Analytics)
- กราฟแท่งสถิติการลาในแต่ละเดือนของปี 2568
- แผนภูมิแถบสัดส่วนการลาแต่ละประเภท
- ปุ่มสั่งพิมพ์รายงาน (Print Report)

---

### 7. ตั้งค่าระบบ (Settings)
- แก้ไขข้อมูลส่วนตัว เช่น ชื่อ ตำแหน่ง แผนก อีเมล เบอร์โทร
- ปุ่มรีเซ็ตข้อมูลตัวอย่างกลับเป็นค่าเริ่มต้น (Reset Mock Data)

---

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เซิร์ฟเวอร์เปิดทำงานอยู่แล้วที่:
👉 **http://localhost:5173/**

หรือหากต้องการรันคำสั่งด้วยตนเอง:
```bash
# 1. ติดตั้ง Dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# 2. รันโหมด Development
npm run dev

# 3. บิลด์สำหรับ Production
npm run build
```
